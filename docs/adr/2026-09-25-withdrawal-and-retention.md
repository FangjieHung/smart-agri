# ADR｜撤回提交與資料保存期限

**狀態：** 已確認（2026-09-25）

## 決策

- 使用者撤回提交時，紀錄內容**真正刪除**，之後重新計算的趨勢與比較不再包含這筆；已產生的定期報表不追溯修改。
- 撤回後只留下不含任何填寫內容的軌跡（曾提交、何時撤回），讓資料管理者知道有一筆資料存在過又被撤回。與前端現有模型一致（`apps/admin/src/app/core/domain/database.model.ts:274`）。
- 對話保存期限由各組織設定：預設永久保存，可改為保存 N 天後自動刪除；助理的「保存對話」關閉時完全不保存對話內容。

## 理由

使用者理解的「撤回」就是刪除；只做匿名化、保留數值在統計中，容易引起個資爭議。保存期限因組織的法規與內規而異，因此做成組織設定。

## 考慮過的選項

- **匿名化保留數值**：統計不受影響，但與使用者對「撤回」的預期不符。
