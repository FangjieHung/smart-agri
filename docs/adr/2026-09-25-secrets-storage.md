# ADR｜機敏設定加密保存且只能寫入

**狀態：** 已確認（2026-09-25）

## 決策

- LINE Channel Secret／Access Token、組織自備的模型 API 金鑰等機敏設定，以 ASP.NET Core Data Protection 加密後存入資料庫；加密金鑰存放在資料庫以外。
- 這些欄位只能寫入、不能讀回：API 只回傳「已設定」與末四碼，前端永遠取不到完整值。

## 理由

資料庫備份或外洩時不致一併洩漏第三方憑證；只能寫入可避免憑證出現在瀏覽器、日誌或截圖中。Data Protection 為 .NET 內建，完全地端部署也可使用。

## 影響

- 部署說明需包含加密金鑰的存放與備份方式；金鑰遺失時，已存的機敏設定需重新輸入。
- 金鑰環存放在檔案系統（客戶部署為 compose volume），並以憑證加密；位置與憑證由部署設定提供，Production 缺少時拒絕啟動（2026-10-06，[M5a 計畫](../plans/2026-10-06-backend-milestone-5a-website-embed.md)第 3 節 G）。網站嵌入的訪客憑證也使用同一個金鑰環。
