# 專案用語

| 畫面用語 | 定義 |
| --- | --- |
| 我的助理 | 同時提供自己建立的助理、草稿，以及公司分享給目前帳號的助理的工作區。 |
| 我建立的 | 目前帳號擁有、可編輯的助理與未完成草稿。 |
| 公司建立的 | 其他帳號建立且目前帳號獲授權使用的助理。 |
| 公司內部分享 | 已登入帳號之間的助理使用權設定；不等於官網或 LINE 對外發布。 |
| 知識庫 | 供助理引用的文件與 FAQ。 |
| 數據庫 | 收集經使用者同意提交的結構化資料，並提供紀錄與趨勢。 |
| Chats | 目前帳號跨助理最近更新的十個已保存對話串。 |
| 草稿 | 尚未完成助理建立流程、可獨立保存與續編的設定。 |
