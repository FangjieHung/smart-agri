# ADR｜助理如何使用知識庫與數據庫

**狀態：** 已確認（2026-09-25）

## 決策

**知識庫**
- 第一版支援有文字層的 PDF、Word（DOCX）、Excel（XLSX）、純文字／Markdown，以及 FAQ。解析使用 PdfPig（Apache-2.0）與 DocumentFormat.OpenXml（MIT）。
- 引用精確到「文件＋頁碼或章節＋原文摘錄」。
- 第一版不做 OCR；無法取出文字的頁面讓文件狀態標為「部分可讀」。OCR 之後以可插拔擴充加入。

**數據庫**
- 助理可以寫入紀錄（請填表單 → 提交回執），也可以讀取紀錄回答問題，例如「這個月噴藥幾次、跟上個月比呢」。
- 讀取只能透過伺服器端事先寫好的固定查詢工具（依期間計數、加總、比較等），參數由模型填入；工具內由服務端依組織與使用者權限過濾，只回傳該使用者有權看到的紀錄。
- 不讓模型自行產生 SQL（NL2SQL）。

## 理由

OCR 與「全地端」路徑衝突：可放在客戶端的 Tesseract 中文辨識普通，雲端 OCR 則讓資料離開客戶環境，因此先不綁定。

模型產生的 SQL 無法保證不越過組織或使用者邊界，也難以稽核；固定查詢工具把權限判斷留在服務端，模型只決定「要問什麼」。

## 影響

- 新的數據庫分析需求要新增查詢工具，而不是放寬模型權限。
- 掃描檔在第一版只能部分引用，需在知識庫畫面清楚提示。
