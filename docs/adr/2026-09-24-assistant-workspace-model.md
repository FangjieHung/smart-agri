# ADR｜助理工作區的歸屬、草稿與對話

**狀態：** 已確認（2026-09-24）

## 決策

- 「我的助理」分成「我建立的」與「組織建立的」。前者包含已建立助理與未完成草稿；後者只包含目前帳號獲授權使用的其他人助理。
- 每次新增都建立新的獨立草稿；草稿以帳號和 ID 識別。舊單份草稿會遷移，避免資料遺失。
- 側欄 Chats 顯示跨可使用助理最近更新的十個私人對話串。對話頁保留該助理的完整清單與改名、刪除操作。
- `/app/channels` 保留，可由助理發布頁面進入；主側欄不顯示發布總覽與「和助理對話」。
- Demo 登入使用三組固定帳號，密碼均為 `1234`，只用於示範身分切換。

## 理由

助理擁有權、使用權與對話所有權是不同概念。列表與側欄都依目前帳號的既有權限結果顯示，避免讓未獲授權的組織助理或其他帳號的對話曝光。草稿需有獨立 ID，才能同時保存並續編多份設定。

## 影響

正式後端整合時，登入驗證、草稿與對話清單需改由服務端執行相同的帳號隔離與授權判斷。前端 Demo 密碼不構成正式驗證。
