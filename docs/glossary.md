# 專案用語

| 畫面用語 | 定義 |
| --- | --- |
| 我的助理 | 同時提供自己建立的助理、草稿，以及組織分享給目前帳號的助理的工作區。 |
| 我建立的 | 目前帳號擁有、可編輯的助理與未完成草稿。 |
| 組織建立的 | 其他帳號建立且目前帳號獲授權使用的助理。 |
| 組織內部分享 | 已登入帳號之間的助理使用權設定；不等於官網或 LINE 對外發布。 |
| 知識庫 | 供助理引用的文件與 FAQ。 |
| 數據庫 | 收集經使用者同意提交的結構化資料，並提供紀錄與趨勢。 |
| Chats | 目前帳號跨助理最近更新的十個已保存對話串。 |
| 草稿 | 尚未完成助理建立流程、可獨立保存與續編的設定。 |
| 組織 | 使用平台的一家公司或團體（例如農會、合作社）。帳號、助理、知識庫、數據庫與對話都只屬於一個組織，不同組織的資料彼此不可見；畫面與文件一律稱「組織」，不用「公司」。 |
| 組織資料 | 助理回答時引用的、來自所屬組織知識庫或數據庫的內容；回答必須能對應到實際檢索到的段落或紀錄。 |
| 一般知識 | 模型本身具備、不出自組織資料的內容；只有助理允許時才提供，且必須與組織資料分開標示。 |
| 撤回 | 提交者收回先前同意提交的紀錄；紀錄內容被刪除，只留下不含內容的軌跡，之後的趨勢不再計入。 |
| 有效紀錄 | 數據庫中尚未撤回的提交（`WithdrawnAt` 為空）；清單、計數、比較與趨勢只計入有效紀錄。 |
| 追蹤對象 | 資料管理者時間軸上的分組單位，即提交資料的帳號；只列出提交到該數據庫的帳號。 |
| 定期報表 | 依數據庫紀錄定期產生的統計與圖表，可附標示為「AI 摘要」的文字說明。 |
| 組織代碼 | 每個組織全系統唯一的簡短代號，登入時用來區分不同組織的同名帳號；只有一個組織的部署可省略。 |
| 對外發布 | 讓組織外的人使用助理，例如官網嵌入或 LINE；必須驗收通過，並受頻率限制與每月用量上限管控。 |
| 官網嵌入 | 在客戶官網貼上載入器程式碼，以對話視窗提供助理；只有允許網域內的網頁能載入。 |
| 允許網域 | 每個助理可以嵌入的官網網域清單；清單為空時無法發布。 |
| 訪客 | 在官網對話視窗使用助理、沒有登入帳號的人；只能詢問知識庫，對話內容不保存。 |
